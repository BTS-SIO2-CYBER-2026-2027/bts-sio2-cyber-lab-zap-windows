# Prompt utilisé pour générer l'application

> **Consigne importante :** vous n'êtes pas limité à un prompt simple. Au contraire, produisez le prompt que vous estimez le meilleur possible.

Vous pouvez demander explicitement : architecture propre, validation des entrées, authentification, contrôle d'accès, protection contre les injections, gestion sûre des mots de passe, en-têtes de sécurité, journalisation, gestion des erreurs, bonnes pratiques OWASP, etc.

Le but du TP n'est **pas** de prouver qu'un mauvais prompt produit une mauvaise application. Le but est d'évaluer objectivement le code réellement produit, même lorsque le prompt est sérieux et détaillé.
